# 📡 TveritnevNet — API Documentation

> Backend-сервер для лендинга Анатолия Тверитнева.
> Стек: **.NET 10**, **PostgreSQL** (через Dapper), собственный MVC-фреймворк **PupaMVCF**.

---

## 🗺️ Все эндпоинты

| Метод | Путь | Доступ | Описание |
|-------|------|--------|----------|
| `GET` | `/configuration/panel` | 🔓 Публичный | Получить конфигурацию панели |
| `GET` | `/configuration/settings` | 🔐 Модератор | Получить конфигурацию настроек |
| `POST` | `/configuration/save` | 🔐 Модератор | Сохранить конфигурацию |
| `POST` | `/moderator/login` | 🔓 Публичный | Войти как модератор |

## ⚙️ Configuration Controller

### `GET /configuration/panel`

Возвращает публичную конфигурацию панели (JSON-объект).

**Авторизация:** не требуется

**Response:**

```
Content-Type: application/json
Status: 200 OK
```

```json
{
  "...": "содержимое panel_json из БД"
}
```

**Ошибки:**

| Статус | Описание |
|--------|----------|
| `!200` | Ошибка десериализации / запись не найдена |

---

### `GET /configuration/settings`

Возвращает конфигурацию настроек. Доступно только авторизованному модератору.

**Авторизация:** 🔐 требуется Cookie `Token` (сессия модератора)

**Response:**

```
Content-Type: application/json
Status: 200 OK
```

```json
{
  "2fa": false,
  "...": "содержимое settings_json из БД"
}
```

**Ошибки:**

| Статус | Описание |
|--------|----------|
| `401 / !200` | Нет активной сессии или истёк токен |
| `!200` | Ошибка десериализации |

---

### `POST /configuration/save`

Сохраняет (перезаписывает) конфигурацию панели и настроек.

**Авторизация:** 🔐 требуется Cookie `Token` (сессия модератора)

**Request body:**

```
Content-Type: application/json
```

```json
{
  "panel": "<валидная JSON-строка>",
  "settings": "<валидная JSON-строка>"
}
```

**Модель `ConfigurationModel`:**

| Поле | Тип | Правила |
|------|-----|---------|
| `panel` | `string` | Обязательно, должен быть валидным JSON |
| `settings` | `string` | Обязательно, должен быть валидным JSON |

**Response:**

```
Status: 200 OK
Body: "success"
```

**Ошибки:**

| Статус | Описание |
|--------|----------|
| `400` | Поля не прошли валидацию (не JSON или пустые) |
| `401 / !200` | Нет активной сессии |
| `!200` | Ошибка обновления в БД |

## 🛡️ Moderator Controller

### `POST /moderator/login`

Авторизует модератора и привязывает токен к сессии.

**Авторизация:** не требуется

**Cookie:** перед запросом у клиента должен быть Cookie `Token` — он будет сохранён в сессии

**Request body:**

```
Content-Type: application/json
```

```json
{
  "username": "admin",
  "password": "secret"
}
```

**Модель `LoginModel`:**

| Поле | Тип | Правила |
|------|-----|---------|
| `username` | `string` | Обязательно, длина 1–128 символов |
| `password` | `string` | Обязательно, длина 1–128 символов |

> ⚠️ Пароль передаётся в открытом виде — хэширование (SHA-256) происходит на сервере.

**Response:**

```
Status: 200 OK
Body: "Success"
```

**Ошибки:**

| Статус | Описание |
|--------|----------|
| `400` | Поля не прошли валидацию |
| `!200` | Неверный логин или пароль |

## 🔐 Авторизация и сессии

Сервер использует **cookie-based сессии**. Схема работы:

1. Клиент генерирует токен и сохраняет его в Cookie `Token`
2. При логине (`POST /moderator/login`) токен из Cookie привязывается к сессии в БД
3. Все защищённые эндпоинты проверяют Cookie `Token` через `ModeratorSessionMiddleware`:
   - Ищут сессию по токену в таблице `session`
   - Проверяют, что сессия не просрочена (`expired_at`)
   - Загружают данные модератора из таблицы `moderator`

**Срок жизни сессии:** 10 дней с момента создания.

## 🗄️ Структура базы данных

### Таблица `moderator`

| Колонка | Тип | Описание |
|---------|-----|----------|
| `id` | `int` | Первичный ключ |
| `username` | `string` | Логин модератора |
| `password_hash` | `string` | SHA-256 хэш пароля |

### Таблица `session`

| Колонка | Тип | Описание |
|---------|-----|----------|
| `id` | `int` | Первичный ключ |
| `user_id` | `int` | ID модератора |
| `token` | `string` | Токен сессии |
| `created_at` | `DateTimeOffset` | Дата создания |
| `updated_at` | `DateTimeOffset` | Дата обновления |
| `expired_at` | `DateTimeOffset` | Дата истечения (+10 дней) |

### Таблица `configuration`

| Колонка | Тип | Описание |
|---------|-----|----------|
| `id` | `int` | Первичный ключ |
| `panel_json` | `string` | JSON конфигурации панели |
| `settings_json` | `string` | JSON конфигурации настроек |

## 🚀 Инициализация при запуске

При старте сервер автоматически:

1. **Создаёт администратора** — если записи с `id=1` нет в таблице `moderator`, создаётся первый модератор из переменных окружения:
   - `ADMIN_USERNAME` — логин
   - `ADMIN_PASSWORD` — пароль (хранится как SHA-256)

2. **Создаёт конфигурации** — если записей с `id=1` и `id=2` нет в таблице `configuration`, они инициализируются из файлов:
   - `public/default.settings.json`
   - `public/default.panel.json`
